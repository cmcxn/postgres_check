# 监控系统完整流程图

## 应用生命周期

```
┌─────────────────────────────────────────────────────────────┐
│                      应用启动                                │
├─────────────────────────────────────────────────────────────┤
│  1. Spring Boot 初始化                                       │
│  2. EmailConfigValidator 验证邮件配置                        │
│  3. 启动完成 (ApplicationReadyEvent)                         │
│  4. StartupNotificationService 发送启动邮件（异步）          │
│  5. 定时任务开始运行                                         │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                   正常运行阶段                               │
├─────────────────────────────────────────────────────────────┤
│  • 数据检查任务：每 5 分钟执行一次                           │
│  • 健康检查任务：每天 8:00 执行一次                          │
│  • 监控数据变化，维护告警状态                                │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                      应用关闭                                │
├─────────────────────────────────────────────────────────────┤
│  1. 接收到关闭信号（Ctrl+C 或 kill）                         │
│  2. ShutdownNotificationService.onShutdown() 触发            │
│  3. 发送关闭通知邮件                                         │
│  4. 等待 2 秒确保邮件发送                                    │
│  5. JVM 退出                                                 │
└─────────────────────────────────────────────────────────────┘
```

## 告警状态机

```
┌────────────────────────────────────────────────────────┐
│                     初始状态                            │
│                   inAlertState = false                  │
│                   alertStartTime = null                 │
└────────────────────┬───────────────────────────────────┘
                     │
                     │ 检测到无数据
                     ↓
┌────────────────────────────────────────────────────────┐
│                    告警状态                             │
│                   inAlertState = true                   │
│              alertStartTime = 当前时间                   │
│                                                         │
│  行为：                                                  │
│  • 发送告警邮件（仅首次）                                 │
│  • 后续检查跳过发送                                      │
│  • 记录告警开始时间                                      │
└────────────────────┬───────────────────────────────────┘
                     │
                     │ 检测到有数据
                     ↓
┌────────────────────────────────────────────────────────┐
│                    恢复处理                             │
│                                                         │
│  计算：                                                  │
│  • 故障时长 = 当前时间 - alertStartTime                  │
│  • 格式化时长描述                                        │
│                                                         │
│  动作：                                                  │
│  • 发送恢复邮件                                          │
│  • inAlertState = false                                │
│  • alertStartTime = null                               │
└────────────────────┬───────────────────────────────────┘
                     │
                     │ 返回正常
                     ↓
┌────────────────────────────────────────────────────────┐
│                    正常状态                             │
│                   inAlertState = false                  │
│                   alertStartTime = null                 │
│                                                         │
│  行为：                                                  │
│  • 继续监控                                              │
│  • 等待下一次检测                                        │
└────────────────────────────────────────────────────────┘
```

## 配置影响范围

```
app.notification.enabled (总开关)
    ↓
    ├─ 影响告警邮件
    └─ 不影响其他通知类型

app.notification.startup-enabled
    ↓
    └─ 仅影响启动邮件

app.notification.recovery-enabled
    ↓
    └─ 仅影响恢复邮件

app.notification.daily-health-check-enabled
    ↓
    └─ 仅影响健康检查邮件

app.notification.shutdown-enabled
    ↓
    └─ 仅影响关闭邮件
```

## 异常情况处理

```
┌─────────────────────────────────────────────────┐
│           可能的异常情况                         │
├─────────────────────────────────────────────────┤
│                                                 │
│  1. SMTP 连接失败                                │
│     └─> 记录错误日志，不影响应用运行             │
│                                                 │
│  2. 邮件发送超时                                 │
│     └─> 记录错误日志，继续下次检查               │
│                                                 │
│  3. 数据库查询失败                               │
│     └─> 记录错误日志，不改变告警状态             │
│                                                 │
│  4. 应用被强制杀死 (kill -9)                     │
│     └─> 无法发送关闭邮件                        │
│                                                 │
│  5. 系统崩溃                                     │
│     └─> 无法发送关闭邮件                        │
│     └─> 下次启动会发送启动邮件                   │
│                                                 │
└─────────────────────────────────────────────────┘
```

---

**说明**：所有流程都经过异常处理，确保单个组件失败不会影响整体系统运行。
